# 🛒 월마트 매출 최적화 데이터 분석 프로젝트

## 1. 프로젝트 개요

본 프로젝트는 월마트의 블랙프라이데이 거래 데이터를 분석하여 매출을 견인하는 **핵심 동력(Key Driver)**을 식별하고, 이를 바탕으로 매출 극대화를 위한 **제품 포트폴리오 최적화 및 번들링(Bundling) 전략**을 수립하는 데 목적이 있습니다.

방대한 거래 데이터 속에서 '누구에게(Customer)'와 '무엇을(Product)' 팔 것인지에 대한 우선순위를 결정하기 위해 다음을 수행합니다.

* **파레토 법칙(Pareto Principle) 검증**: 제품 및 고객별 매출 기여도 비교 분석
* **세그멘테이션(Segmentation)**: 고매출 제품군의 특성(가격 vs 판매량) 분류
* **전략 수립**: 고가(High-Price) 전략 vs 다량판매(Volume) 전략 비교 및 검증
* **교차 판매(Cross-selling) 분석**: 장바구니 분석을 통한 동반 구매 패턴 식별 및 번들링 타겟 도출

## 2. 데이터 출처

* **데이터셋**: 월마트(Walmart) 상점 거래 내역 (`walmart.csv`)
* **데이터 규모**: 총 550,068건 (Row), 10개 속성

### 주요 컬럼
* `User_ID`: 고객 식별 ID
* `Product_ID`: 제품 식별 ID
* `Purchase`: 구매 금액 (매출, Target Variable)
* `Product_Category`: 제품 카테고리 (분류 코드)
* `Gender`, `Age`, `Occupation`: 고객 인구통계학적 정보
* `City_Category`, `Stay_In_Current_City_Years`: 거주 지역 및 기간 정보

## 3. 기술 스택

* **Python**
* **Pandas, NumPy**: 데이터 전처리, 집계(Aggregation), 파생변수 생성
* **Matplotlib, Seaborn**: 파레토 차트, 산점도, 도넛 차트, 히트맵 등 데이터 시각화

## 4. 분석 목표 및 주요 내용

### 🎯 핵심 목표
1.  **매출 기여도 비교 (Product vs Customer)**: 마케팅 리소스를 '제품 관리'와 '고객 관리' 중 어디에 집중할지 결정
2.  **고부가가치 제품 분석**: 상위 20% 핵심 제품군의 매출 발생 원인(Price vs Volume) 규명
3.  **번들링 전략 수립**: 객단가(Ticket Size) 극대화를 위한 '동반 구매' 패턴 식별 및 패키지 상품 기획

### 📊 주요 분석 과정

1.  **파레토 분석 (Pareto Analysis)**
    * 제품별, 고객별 매출 집중도 확인
    * **결과**: 상위 20% 제품이 전체 매출의 **73.3%**를 견인함 (vs 고객 55.3%) → **제품 중심 접근 채택**

2.  **가격 전략 검증 (Price vs Volume)**
    * 상위 제품군을 가격대별(Low/Mid/High)로 세그먼테이션하여 매출 비중 분석
    * **결과**: **High Price(고가)** 제품군이 전체 매출의 **50.3%**를 점유하며 압도적 1위 기록

3.  **장바구니 분석 (Market Basket Analysis)**
    * 핵심 카테고리(Cat 1, 5, 10) 구매자의 동시 구매 패턴 분석 (신뢰도 산출)
    * **결과**: **Category 1, 5, 8** 간의 강력한 상호 의존성 확인 (동시 구매 확률 96% 이상)

## 5. 결론 및 인사이트

* **전략 방향**: 단순 판매량(Volume) 증대보다 **'고단가 제품의 패키지 판매(Bundling)'**가 매출 확보에 유리함.
* **핵심 발견**:
    * **고가(High Price) 세그먼트**가 전체 매출의 과반(**50.3%**)을 견인함.
    * **Category 1** 구매자의 약 **97%**가 **Category 5, 8**을 함께 구매하는 '트리플 클러스터' 패턴을 보임.
* **Action Plan**:
    * **All-in-One 패키지**: Category 1, 5, 8을 묶은 프리미엄 번들 상품을 최상단 노출하여 락인(Lock-in) 유도.
    * **재고 동기화(Inventory Sync)**: 판매 속도가 동일한 세 카테고리(1, 5, 8)에 대해 통합 안전 재고 관리 체계 구축.
    * **잠재적 스타 육성**: 매출 비중은 적지만 고가 라인업인 **Category 10**을 주력 구매층에게 크로스 셀링(Cross-selling)하여 육성.
