# 🛒 월마트 블랙프라이데이 매출 분석 프로젝트

## 1. 프로젝트 개요

본 프로젝트는 월마트의 블랙프라이데이 거래 데이터를 분석하여 매출을 견인하는 **핵심 동력(Key Driver)**을 식별하고, 이를 바탕으로 매출 극대화를 위한 **제품 포트폴리오 최적화 전략**을 수립하는 데 목적이 있다.

방대한 거래 데이터 속에서 '누구에게(Customer)'와 '무엇을(Product)' 팔 것인지에 대한 우선순위를 결정하기 위해 다음을 수행한다.

* **파레토 법칙(Pareto Principle) 검증**: 제품 및 고객별 매출 기여도 비교 분석
* **세그멘테이션(Segmentation)**: 고매출 제품군의 특성(가격 vs 판매량) 분류
* **전략 수립**: 고가(High-Price) 전략 vs 다량판매(Volume) 전략 비교 및 검증
* **타겟 도출**: 전략 실행을 위한 핵심 **Product Category** 추출 및 시각화

## 2. 데이터 출처

* **데이터셋**: 월마트(Walmart) 상점 거래 내역 (`walmart.csv`)
* **데이터 규모**: 총 550,068건 (Row)

### 주요 컬럼
* `User_ID`: 고객 식별 ID
* `Product_ID`: 제품 식별 ID
* `Purchase`: 구매 금액 (매출, Target Variable)
* `Product_Category`: 제품 카테고리 (분류 코드)
* `Gender`, `Age`, `Occupation`: 고객 인구통계학적 정보

## 3. 기술 스택

**Python 3.12.9**
* **Pandas, NumPy**: 데이터 전처리, 집계(Aggregation), 파생변수 생성
* **Matplotlib, Seaborn**: 파레토 차트, 산점도, 도넛 차트 등 데이터 시각화

## 4. 분석 목표 및 주요 내용

### 🎯 핵심 목표
1.  **매출 기여도 비교 (Product vs Customer)**: 마케팅 리소스를 '제품 관리'와 '고객 관리' 중 어디에 집중할지 결정
2.  **고부가가치 제품 분석**: 상위 20% 핵심 제품군의 매출 발생 원인 규명
3.  **시각적 스토리텔링**: 데이터 기반의 구체적인 액션 플랜(카테고리 선정) 제시

### 📊 주요 분석 과정
1.  **파레토 분석 (Pareto Analysis)**
    * 제품별, 고객별 매출 집중도(Gini Coefficient 유사 개념) 확인
    * *결과: 상위 20% 제품이 전체 매출의 73%를 견인함 (제품 중심 접근 채택)*
2.  **가격 전략 검증 (Price vs Volume)**
    * 상위 제품군을 가격대별(Low/Mid/High)로 세그먼테이션하여 매출 비중 분석
    * 제품별 가격 변동성(CV) 분석을 통해 '객단가(Ticket Size)' 개념의 타당성 확보
3.  **핵심 카테고리 도출**
    * 고가 전략(High Price Strategy) 실행을 위한 최우선 순위 카테고리(Category 1, 5, 8) 식별

## 5. 결론 및 인사이트

* **전략 방향**: '박리다매(Volume)'보다 **'객단가(Ticket Size) 증대'**가 매출 확보에 유리함.
* **핵심 발견**:
    * **고가(High Price) 세그먼트**가 전체 매출의 약 **50.3%**를 차지하며 압도적인 기여도를 보임.
    * 상위 제품군은 하위 제품군 대비 가격 변동성이 낮아(CV 0.26 vs 0.33), 안정적인 고수익 창출이 가능함.
* **Action Plan**:
    * 매출 기여도가 절대적인 **Category 1, 5, 8** 제품군에 대한 **안전 재고(Safety Stock)** 우선 확보.
    * 불특정 다수를 향한 할인 프로모션보다, 구매력을 갖춘 고객을 대상으로 한 **프리미엄 번들링(Bundling)** 마케팅 전개.
